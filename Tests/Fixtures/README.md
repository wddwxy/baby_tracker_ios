# 合成 fixtures

这些文件是原型计划 2.4 节固定数据集的可读快照。

## 当前状态（步骤 01）

只提供 **F0** 和 **F1**：

| 文件 | 数据集 | 内容 |
| --- | --- | --- |
| `F0.json` | F0 | 空宝宝资料、无任何记录 |
| `F1.json` | F1 | 每个活动类别各一条固定记录，时间固定 |

`F0.json` / `F1.json` 与 `Sources/Domain/Demo/DemoFixtures.swift` 使用同一份数据，字段形状是
`DemoDataset` 的编码结果（日期为 ISO 8601，时间点统一为 `2026-10-16T01:00:00Z`）。

- Swift 单元测试 `DemoFixturesTests` 会解码这两个文件并核对关键不变量。
- `ios/scripts/check-fixtures.py` 在不依赖 Xcode 的机器上做同样的结构校验。

## 规则

- fixtures 一律是合成数据，不得包含真实宝宝记录、生产导出或凭证（计划测试 01-06）。
- 时间必须写死，不能使用"当前时间"，否则 UI 测试无法重复（计划测试 01-05）。
- 未知字段与缺失可选字段要单独保留为用例，不要为了解码方便删掉。
